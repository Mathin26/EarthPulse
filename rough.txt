# 🌍 EarthPulse — Global Impact Platform

## Project Overview
EarthPulse is a **university MOQ-based testing project** built with **.NET 8 + C#** demonstrating advanced patterns:
- **RAG (Retrieval-Augmented Generation)** with vector search
- **MOQ unit testing** framework (Moq v4.20)
- **Real-time SignalR** updates
- **PageRank algorithm** for impact scoring
- **Climate & societal impact** data aggregation

---

## 🏗️ Architecture

### Tech Stack
- **Backend**: ASP.NET Core 8 Web API
- **Testing**: MOQ (Moq v4.20) + xUnit
- **Frontend**: React SPA (HTML5/CSS3)
- **Real-time**: SignalR WebSockets
- **Database**: PostgreSQL + pgvector (for embeddings)
- **AI**: OpenAI embeddings + RAG pipeline

### Example MOQ Test (RAGService)
```csharp
[Fact]
public async Task QueryAsync_ReturnsAugmentedResponse()
{
    // Arrange
    var mockDocs = new List<VectorDocument>
    {
        new() { Content="CO2 emissions...", Score=0.94f },
        new() { Content="Deforestation...", Score=0.87f }
    };

    _mockVectorStore
        .Setup(v => v.SearchAsync(It.IsAny<float[]>(), 5))
        .ReturnsAsync(mockDocs);

    _mockAIService
        .Setup(a => a.GenerateAsync(It.IsAny<RAGPrompt>()))
        .ReturnsAsync("Global warming is primarily driven by CO2...");

    // Act
    var result = await _sut.QueryAsync("What causes global warming?");

    // Assert
    Assert.NotNull(result.Answer);
    Assert.Equal(2, result.Sources.Count);
    _mockVectorStore.Verify(v => v.SearchAsync(It.IsAny<float[]>(), 5), Times.Once);
}
```

## 🤖 RAG Implementation

### How It Works
1. **Query Embedding**: User query → OpenAI embedding (1536-dim vector)
2. **Vector Search**: Cosine similarity search in pgvector store
3. **Context Retrieval**: Top-5 matching documents retrieved
4. **Augmented Prompt**: System prompt + context + query
5. **Generation**: OpenAI generates grounded response with sources

### Key Classes
- **RAGService**: Orchestrates embedding → search → generation
- **InMemoryVectorStore**: O(n) cosine similarity search
- **VectorSearchService**: Vector indexing & retrieval
- **PromptDatabase**: 500+ seeded climate & impact facts

## 🚀 Getting Started

### Prerequisites
- .NET 8 SDK
- PostgreSQL with pgvector extension
- OpenAI API key
- Node.js 18+ (for React frontend)

### Setup Instructions

#### 1. Clone & Restore
```bash
git clone <repo-url>
cd EarthPulse
dotnet restore
```

#### 2. Database Setup
```bash
# Create PostgreSQL database
createdb earthpulse

# Apply migrations
dotnet ef database update --project EarthPulse.Infrastructure
```

#### 3. Configuration
Create `appsettings.json`:
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Database=earthpulse;..."
  },
  "OpenAI": {
    "ApiKey": "sk-...",
    "EmbeddingModel": "text-embedding-3-large"
  }
}
```

#### 4. Run Tests
```bash
dotnet test EarthPulse.Tests --verbosity normal
```

#### 5. Start API
```bash
dotnet run --project EarthPulse.API
# API runs on https://localhost:7241
```

#### 6. Open HTML Platform
```bash
# Open earthpulse_global_impact_platform.html in browser
open earthpulse_global_impact_platform.html
```
